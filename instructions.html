Getting Started

Use the tabs at the top of the screen to switch between selecting files to combine, configuring output settings/options, and displaying this help file.

"Merge" and "Combine" are used interchangeably in this application.

The file list shows the files in the order in which they will be combined into a single "merged" PDF file.

Adding Files to Combine

  • Supported file formats are: PDF, JPG, JPEG, PNG, BMP, GIF, TIF, and TIFF.
  • Images are converted a single page PDF during a merge.
  • Adding the same file to the list more than once is not permitted.
  • PDF files appear in black text; images appear in blue text.

Main Screen Buttons

Add Files:

Click to open a file browser window. Select one or multiple files using the file browser. Single click to select one file, Ctrl‑Click to select multiple files, or Shift‑Click to select multiple contiguous files. The selected files will be added to the file list.

Add Folder:

Click to open a folder browser and select a folder. All files from the folder and its subfolders will be added to the file list.

Remove Selected:

Clicking or Ctrl‑Clicking files in the file list will select files. The selected file rows will be highlighted. Clicking this button will remove the selected file(s) from the file list. Note: the file are NOT deleted from disk, only removed from the list.

Move Up:

Click this button to move a selected file up in the list order.

Move Down:

Click this button to move a selected file down in the list order.

Clear All:

Clear all the files in the file list regardless of selection. Note: the files are NOT deleted from disk, only removed from the list.

Save List:

Exports the current file list and per‑file settings (rotation, pages, reversal) to a .pdflist file. This is useful for processing sets of files in recurring workflows.

Load List:

Imports a previously saved .pdflist file. Saved lists preserve rotation, page ranges, and reverse settings. The loaded files from the list will be displayed in the file list.

Output File / Browse:

Click Browse to choose a save location and filename for the combined PDF.

The File List

  • Files are combined in the order shown in the file list.
  • You can add and remove files when other files are shown in the list.
  • Hover over a file to see a preview and the file's full path and name.
  • Click column headers (Filename, File Size, Date) to sort; click again to reverse.
  • Note that sorting by a column resets any manual ordering.

Pages / Rotation / Reversal Columns

Note: Double‑click in the cell in the Pages, Rotation (Rot), or Reverse (Rev) column on the same line as the file you want to modify. After double-clicking, the cell becomes editable.

Pages *

  • Specifies which pages to extract from the source file:
    • All or blank → include all pages
    • Single page: 5
    • Range: 1‑10
    • Multiple ranges: 1‑3,5,7‑9

Rotation (Rot)

  • Rotate pages by 0°, 90°, 180°, or 270° in a clockwise direction.
  • Zero (0°) rotation doesn't rotate the image.

Reverse (Rev) *

  • Reverses the page order for a file.
  • An '✗' means the pages won't be reversed, a '✓ ' means they will be.
* These choices are not applicable for image files since an image is compsed as a single page.

Options / Settings

  • Add a Table of Contents (TOC): Creates a clickable TOC as the first page in the combined PDF. Creation date and other information may optionally be added to the TOC.
  • Add filename bookmarks: Creates bookmarks from each source filename in the merged PDF.
  • Insert breaker pages: Adds labeled separator pages before each file.
  • Scale all breaker pages to uniform size: Forces consistent dimensions of the breaker pages. If not selected the breaker page is sized the same as the first page of the file it references.
  • Ignore blank pages: Skips blank pages unless they fall in the page range to be extracted.
  • Compression/Quality: Compresses the merged PDF. Higher compression reduces size but lowers quality.
  • Add PDF metadata: Set Title, Author, Subject, Keywords as the metadata for the merged PDF.
  • Add watermark: Apply text across all pages with opacity, size, rotation options.
  • Scaling: Scale the merged PDF.
  • Encryption: Add user/owner passwords to encrypt the merged PDF for security.

Combining Considerations

  • Each PDF is fully loaded into RAM, so try to keep individual PDFs under 100 MB.
  • Combining 2–50 files is typically quite fast. Combining 50–100+ files quickly depends on the RAM available and merged file size.
  • Compression, scaling, and watermarking increase CPU/RAM usage.
  • Available system RAM limits maximum workable sizes.
  • Output size is limited only by disk space and memory.
  • Very large numbers of files or a very large merged file may cause slow progress updates and high memory usage.
