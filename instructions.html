Getting Started

Use the tabs at the top of the screen to switch between selecting files to add to the file list, configuring output settings/options, and displaying this help file.

The file list shows the files and the order in which they will be combined. "Merge" and "Combine" are used interchangeably in this application.

Adding Files to Combine

  • Supported file formats are: PDF, JPG, JPEG, PNG, BMP, GIF, TIF, and TIFF.
  • Images are converted to a PDF page during a merge.
  • Adding the same file to the list more than once is not permitted.
  • PDF files appear in black text; images appear in blue text.

Main Screen Buttons

Add Files:

Click to open a file browser window. Select one or multiple files using the file browser. Single click to select one file, Ctrl‑Click to select multiple files, or Shift‑Click to select multiple contiguous files. The selected files will be added to the file list.

Add Folder:

Click to open a folder browser and select a folder. All files from the folder and its subfolders will be added to the file list.

Remove Selected:

Clicking or Ctrl‑Clicking files in the file list will select files. Clicking this button will remove the selected files from the file list. Note: the file will NOT be deleted from disk, only removed from the list.

Move Up:

Click this button to move a selected file up in the list.

Move Down:

Click this button to move a selected file down in the list.

Clear All:

Clear all the files in the file list regardless of selection.

Save List:

Exports the current file list and per‑file settings (rotation, pages, reversal) to a .pdflist file. Useful for recurring workflows.

Load List:

Imports a previously saved .pdflist file. Saved lists preserve rotation, page ranges, and reverse settings.

Output File / Browse:

Click Browse to choose a save location and filename for the combined PDF.

The File List

  • Files are combined in the order shown in the file list.
  • You can add files when other files are shown in the list.
  • Hover over a file to see a preview and the file's full path and name.
  • Click column headers (Filename, File Size, Date) to sort; click again to reverse.
  • Sorting resets manual ordering.

File Pages / Rotation / Reversal Columns

Note: Double‑click in the cell in the Pages, Rotation (Rot), or Reverse (Rev) column on the same line as the file you want to modify.

Pages

  • Specifies which pages to extract:
    • All or blank → include all pages
    • Single page: 5
    • Range: 1‑10
    • Multiple ranges: 1‑3,5,7‑9
  • Not available for images.

Rotation (Rot)

  • Rotate pages or images by 0°, 90°, 180°, or 270° clockwise.
  • Zero (0°) rotation doesn't rotate the image.

Reverse (Rev)

  • Reverses the page order for a file.
  • Not available for images.
  • An '✗' means the pages won't be reversed, a '✓ ' means they will be.

Options / Settings

  • Add a Table of Contents: Creates a clickable TOC in the combined PDF.
  • Add filename bookmarks: Creates bookmarks from each source filename.
  • Insert breaker pages: Adds separator pages before each file.
  • Scale all breaker pages to uniform size: Forces consistent dimensions.
  • Ignore blank pages: Skips blank pages unless specifically selected.
  • Compression/Quality: Higher compression reduces size but lowers quality.
  • Add PDF metadata: Set Title, Author, Subject, Keywords.
  • Add watermark: Apply text across all pages with opacity, size, rotation.
  • Scaling: Scale the combined PDF.
  • Encryption: Add user/owner passwords to encrypt the PDF.

Combining Considerations

  • Each PDF is fully loaded into RAM; keep individual PDFs under 100 MB.
  • Combining 2–50 files is typically fast; 50–100+ depends on RAM and file size.
  • Compression, scaling, and watermarking increase CPU/RAM usage.
  • Available system RAM limits maximum workable sizes.
  • Output size is limited only by disk space and memory.
  • Very large outputs may cause slow progress updates and high memory usage.
