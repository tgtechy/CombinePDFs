PDF Combiner – Instructions

Getting Started

Use the tabs at the top of the screen to switch between selecting files to add to the file list, and configuring output settings/options.

"Merge" and "Combine" are unsed interchangably in this application.

Adding Files to Combine

  • Supported formats are: PDF, JPG, JPEG, PNG, BMP, GIF, TIFF.
  • Images are converted to PDF during a merge.
  • Adding the same file more than once is not permitted; only one copy of a unique filepath/filename will appear in the list
  • PDF files appear in black text; images appear in blue text. 

Add Files:

  • Select one or multiple files using the file browser. Use Ctrl-Click to select multiple invidual files, or Shift-Click to selected multiple contiguous files.

Add Folder:

  • Adds all files from a folder and its subfolders.

Load List:

  • If you have stored lists of files, you can load all the files from a list by selecting it from the file browser.

Organizing Files

  • After files are loaded into the list, click a file to select it, then use the Move Up/Move Down buttons to reorder.
  • Files are combined in the order shown in the file list.
  • Use Click and Ctrl+Click to select multiple files for deletion.
  • Hover over a file to see a preview and its full path and name.

Saving and Loading Lists

Click Load List or Save List to manage file lists:

Save List

  • Exports the current file list and per-file settings (rotations, pages, reversal) to a .pdflist file.
  • Useful for recurring workflows where you merge a preset set of files.

Load List

  • Imports a previoulsy saved .pdflist file.
  • Duplicate files are skipped automatically.
  • Saved lists preserve rotation, page ranges, and reverse settings.

Sorting

  • Click column headers (Filename, File Size, Date) to sort the files in the list.
  • Click again to reverse the sort order.
  • Note that sorting resets any custom manual ordering.

File List Properties

Note: Double‑click in the cell in the Pages, Reverse, or Rotation column that is on the same line as a file you want to modify.

Pages

  • Specifies which pages to extract from a file when merging.
  • All or blank → include all pages when merging.
  • Single page: 5
  • Page Range: 1-10
  • Multiple ranges: 1-3,5,7-9
  • This selection is not available for images.

Reverse (Rev)

  • Reverses the page order for a file when merging.
  • This selection is not available for images.

Rotation (Rot)

  • Rotate pages by 0°, 90°, 180°, or 270° clockwise.
  • For images, rotation is applied during PDF conversion.

Output Settings

  • Click Browse to choose a save location.
  • Enter a filename for the combined PDF.

Optional Output Features

  • Add a Table of Contents: Creates a clickable table of contents with page number references.
  • Add filename bookmarks: Creates bookmarks from each source file name.
  • Insert breaker pages: Adds separator pages before each file.
  • Scale all breaker pages to uniform size: Forces consistent breaker page dimensions.
  • Ignore blank pages: Skips blank pages in source PDFs, unless specific pages are selected in which case if the page(s) are blank in the selection range, it will be retained.
  • Compression/Quality: Higher compression reduces size but lowers quality.

Metadata and Watermark

  • Add PDF metadata: Set Title, Author, Subject, and Keywords.
  • Add watermark: Apply text across all pages with customizable opacity, size, and rotation.

Status Bar

  • The bottom status bar shows the number of files and their total size.

Memory Considerations

  • Each PDF is fully loaded into RAM.
  • For best performance, keep individual PDFs under 100 MB.

Number of PDFs to Combine

  • There is no hard-coded limit.
  • Combining 2–50 files is typically fast and reliable.
  • 50–100+ files may slow processing depending on file sizes and available RAM.

Combined Output Size

  • Limited only by disk space and system memory.
  • Very large outputs (1000+ pages or multiple large PDFs) may cause:
    • Slow progress updates
    • High memory usage during compression
    • Long write times

Real‑World Guidelines

  • Try to keep each source PDF under 100 MB.
  • Combining 2–50 files works fine; 50–100+ can be combined depending on size and your computer's RAM.

Key Factors Affecting Performance

  • Compression increases RAM and CPU usage.
  • Page scaling and watermarks add overhead.
  • Available system RAM limits maximum workable size.
